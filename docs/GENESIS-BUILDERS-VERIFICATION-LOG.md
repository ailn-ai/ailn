# Verification log

One entry per independent verification. Newest first. Each entry names what was measured, how, and
the command used — so the next reader can repeat it rather than trust it.

Format:

```
## YYYY-MM-DD · <what was verified>
- claim: <the sentence being checked>
- method: <command or action>
- result: <agrees | contradicts | undetermined>
- evidence: <paste>
```
