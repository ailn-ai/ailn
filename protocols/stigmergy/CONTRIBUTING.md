# Contributing to stigmergy

**This protocol has no implementation.** Contributions are documents, critique, and analysis.

---

## Most useful

Schema review, a concrete Proof format for one task type, prior art, and attack analysis of fake proofs.

## Accepted

- A critique that names a specific weakness and what would fix it
- Prior art with a link, including prior art that shows this is redundant
- A threat model enumerating how the design fails
- A narrower, more concrete version of an idea already sketched

## Not accepted

- An implementation (there is no agreed schema to implement)
- Claims that the protocol is running, deployed, or audited
- Marketing language
- New components added without removing something else and explaining why

## Bar

A contribution should make it possible for a reader to say "this design fails in situation X"
or "this design handles X" — concretely, not in general.

See the repository `CONTRIBUTING.md` for commit and PR conventions.
